# 复盘：漏报国家统计局2026年1—7月固定资产投资

- 复盘时间：2026-08-23T17:58:23+08:00
- 范围：`cn-nbs-activity`，仅核查2026-08-14至2026-08-21的计划、运行记录、日报和国家统计局原文；不补写历史数据卡，不改状态水位。

## 结论

确有漏报。`cn-nbs-activity`已注册为P0国家统计局日历驱动数据集，指标明确包括固定资产投资；本地仅保存了1—6月/二季度版本，未保存2026年8月17日发布的1—7月版本。8月17日、18日的日报也未提及该发布。

## 官方事实

- 国家统计局于2026-08-17发布《2026年1—7月份全国固定资产投资基本情况》：固定资产投资（不含农户）260328亿元，同比下降6.7%；扣除房地产开发后下降3.7%；7月环比下降1.42%。
- 相比本地上一版1—6月累计同比下降5.7%，累计降幅扩大1.0个百分点；该比较须保留累计同比和可比口径边界。
- 同期基础设施投资下降3.6%、制造业投资下降1.7%、房地产开发投资下降19.2%、民间投资下降9.4%。
- 官方原文：https://www.stats.gov.cn/sj/zxfbhjd/202608/t20260817_1965054.html

## 运行证据与根因

1. `schedule.json`在2026-08-16刷新后，仍把该数据集的预计发布时间设为2026-08-14 09:30、覆盖窗口设为8月14—15日；实际发布为8月17日，发布日历已失配。
2. 2026-08-16的运行把`cn-nbs-activity`记为成功检查并将`last_checked_at`推进至2026-08-16，但没有产生该数据集的新卡或错误记录；当时官方新稿尚未发布。
3. 8月17日和18日虽有日报运行，但已推进的水位与过期窗口使该P0数据集不再进入`due_datasets`，因此没有对国家统计局发布列表做迟发补扫。
4. 这不是来源未注册、去重判为未变或重要性被主观降级，而是“预计日=覆盖完成”的错误控制：日历只能触发检查，不能在没有匹配官方发布的情况下关闭迟发风险。

## 影响与反省

漏掉的不是边缘分项，而是全国投资、房地产与内需判断的核心P0发布；在累计降幅由-5.7%扩大到-6.7%、且扣除房地产后的投资也转弱时，至少应成为全国判断的中等重要性证据。把它漏掉会使8月中旬日报对内需和投资的判断不完整，尤其削弱对金融数据中住户融资偏弱的交叉验证。

## 后续控制要求（本复盘不实施）

- 日历驱动数据必须以“匹配到官方新稿或明确记录访问失败”为完成条件；仅越过预计窗口不得推进成功水位。
- 预计发布日期后的至少一个工作日应保留迟发复扫，直到官方列表确认本期发布。
- 日历刷新发现预期日期已过去而本地没有对应参考期记录时，应自动形成补扫候选，不能把旧窗口视为已覆盖。
- P0综合月度发布应同时核对总述稿与固定资产投资、房地产等专题稿，防止只抓到同日其他数据集而漏掉核心分项。

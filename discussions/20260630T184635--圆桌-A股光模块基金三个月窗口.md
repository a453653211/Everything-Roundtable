# 圆桌：A股光模块基金三个月窗口

日期：2026-06-30

## 议题

用户判断：A股科技相对美股仍被低估；中国光模块在全球持续领先并有议价权；AI网络设备中光模块费用占比高，且相比光棒光纤仍有升级和替换空间；因此考虑在当前时间点重仓买入光模块基金，持仓三个月后看涨。

本场目标：判断这个仓位动作的逻辑强弱、三个月窗口的胜率来源和主要风险。本文为分析框架，不构成投资建议。

## 事实底座

1. AI光模块需求处于高景气。TrendForce 2026-04-20预计，全球AI光模块市场规模将从2025年的165亿美元扩至2026年的260亿美元，同比增长超过57%；800G及以上光模块需求由北美超大规模数据中心AI集群互联驱动。来源：https://www.trendforce.com/presscenter/news/20260420-13017.html

2. 供给侧仍有瓶颈。TrendForce指出，EML、CW激光器、光耦合、功耗与热管理是扩产瓶颈；上游供应商和系统厂商通过长期协议保障关键零部件。来源同上。

3. 中国厂商在高容量可插拔光模块制造环节有强竞争力。TrendForce 2026-05-05称，中国供应商凭借规模和成本优势，长期在全球光通信市场占主导；Innolight和Eoptolink在以太网收发器等大规模产品中有强成本竞争力。来源：https://www.trendforce.com/presscenter/news/20260505-13031.html

4. 但上游关键器件不完全由中国厂商控制。Cignal AI 2025-05-07指出，Innolight、Coherent、Eoptolink是数通模块主要供应商；Coherent、Broadcom、Lumentum是关键光组件重要来源。来源：https://cignal.ai/2025/05/800gbe-optics-shipments-to-grow-60-in-2025/

5. CPO短期不会立刻替代可插拔光模块。Cignal AI同文称，1.6T数通光模块从2025年开始过渡，但未来三年CPO对可插拔出货没有实质影响。

6. 下游AI资本开支仍强。NVIDIA 2026-05-20披露，FY2027 Q1收入816亿美元，同比+85%；Data Center收入752亿美元，同比+92%。来源：https://investor.nvidia.com/financial-info/financial-reports/default.aspx

7. A股光模块龙头业绩已经兑现一部分。21财经援引中际旭创2026一季报：Q1营收194.96亿元，同比+192.12%，环比+47.31%；归母净利润57.35亿元，同比+262.28%，环比+56.45%。来源：https://www.21jingji.com/article/20260417/herald/bd13f82ae89e1e7ed0958a8c579adc59.html

8. 新易盛也高增但出现预期差。财联社称新易盛2025年营收248.42亿元，同比+187.29%，归母净利润95.32亿元，同比+235.89%；2026Q1营收83.38亿元，同比+105.76%，归母净利润27.80亿元，同比+76.80%，但环比2025Q4下降13%，且低于部分市场预期。来源：https://m.cls.cn/detail/2354227

9. 光模块基金高度集中。新浪财经2026-06-16称创业板人工智能ETF华宝（159363）标的指数光模块含量约50%，“易中天”含量高；截至2026-06-12规模71.75亿元，近6个月日均成交超9亿元。来源：https://finance.sina.com.cn/money/fund/etf/2026-06-16/doc-inicrcpp7603651.shtml

10. 天天基金显示创业板人工智能ETF华宝（159363）2026-06-29单位净值1.4882，日跌1.35%，净资产规模55.64亿元（截至2026-03-31），风险需以基金公告和实时交易数据核验。来源：https://fundf10.eastmoney.com/ccbd_159363.html

11. 2026-06-30资金短线回流通信板块。证券时报称当天通信行业涨4.89%，主力资金净流入112.77亿元；新易盛净流入45.33亿元，中际旭创净流入19.25亿元，但天孚通信净流出4.59亿元。来源：https://www.stcn.com/article/detail/3989220.html

12. 光模块成本占比要按分母区分。若分母是系统设备/光通信设备，公开报道中常见“占系统设备成本超50%”；若分母是整个数据中心IT设备，券商报告常见约5%或高于5%的判断。该差异会影响“光模块费用占比特别高”的结论强度。

## 席位一：产业赛道 lens

结论：长期产业逻辑强，三个月上涨并非没有基础，但“重仓”的核心风险在于产业好不等于价格便宜。

推理：
- 需求端：AI集群扩张、800G/1.6T升级、北美CSP资本开支仍是真变量。
- 供给端：瓶颈在高端光芯片、激光器、光耦合、热管理和良率；龙头已有订单、产能、客户认证优势。
- 商业模式：高速产品占比提升可提升毛利；新产品年降风险暂时被迭代速度对冲。
- 拐点：三个月窗口看中报、2027订单明朗化、上游缺料缓解、1.6T放量节奏。

最大不确定性：市场是否已经把2026-2027的乐观预期充分计入估值。

## 席位二：宏观/交易 lens

结论：三个月交易不是“低估修复”，而是“业绩验证 + 拥挤趋势”的高波动交易。

推理：
- 当前不是无人问津的低位产业链，而是全市场最强主线之一。
- 6月30日通信、电子大幅回流说明资金仍愿意抱团景气方向，但同一天龙头内部已有分化。
- ETF把个股基本面风险打包成高beta主题风险：中际旭创强，新易盛预期差，天孚资金流出，都会直接影响基金净值。
- 三个月窗口如果兑现上涨，大概率来自Q2/中报继续超预期、2027订单口径上调、海外AI资本开支继续上修；不是单纯来自“A股科技便宜”。

最大不确定性：若业绩只是好但不超预期，拥挤交易容易转为获利了结。

## 席位三：反方风控 lens

结论：可以看多产业，但不应把“全球领先”简化成“绝对议价权”，也不应把“基金分散”误认为“风险低”。

推理：
- 中国厂商在模块制造、交付、成本上强，但关键上游光芯片、DSP、激光器、硅光/CPO生态仍有海外关键环节。
- 可插拔光模块未来三年受CPO冲击有限，但CPO、OCS、NPO、LPO等技术路线会改变估值叙事和公司相对位置。
- 光模块基金集中度高，本质更像“光模块龙头组合”，不是宽基科技基金。
- 汇率、关税、出口管制、客户集中、库存与预付款增长，都可能在三个月窗口内触发波动。

最大不确定性：交易者是否有可执行的退出规则，而不是只用产业叙事扛回撤。

## 趋同与分歧

趋同：
- 产业景气为真，不是纯题材。
- 中国龙头在高端数通光模块的制造与交付上有全球竞争力。
- 三个月看涨的合理触发器是中报/订单/产能/上游瓶颈，而不是“泛科技低估”。
- 当前不适合把它定义为低风险重仓。

分歧：
- 产业席更愿意给三个月窗口较高胜率。
- 宏观交易席强调拥挤交易和预期差。
- 风控席认为仓位动作比方向判断更关键，尤其反对一次性重仓。

## 结构图

```
AI资本开支
  -> GPU/TPU集群扩张
    -> 网络带宽升级
      -> 800G/1.6T光模块需求
        -> 龙头收入/毛利增长
          -> 中报与订单验证
            -> 基金价格上涨

同时：
估值已高 + 持仓拥挤 + 客户集中 + 汇率/监管/技术路线
  -> 好消息需继续超预期
  -> 不超预期也可能下跌
```

## 终局判断

一句话：光模块产业逻辑仍强，三个月看涨有基本面触发器，但当前买入更像高波动趋势交易，不是低估价值投资；“重仓”需要被仓位纪律替代。

如果只是判断方向：偏多，但信心来自业绩验证，不来自低估。

如果判断是否重仓：不赞成一次性重仓。更稳妥的表达是分批、设验证点、设失效条件。

三个月窗口最该盯：
- 2026Q2/中报是否继续环比增长，特别是收入、毛利率、经营现金流、存货、预付款。
- 2027年订单与1.6T量产口径是否更明确。
- 上游EML/CW激光器等瓶颈是缓解并放量，还是造成交付/毛利压力。
- NVIDIA、Google、Meta、Microsoft等AI资本开支和网络架构是否上修。
- ETF成分中“易中天”是否同步走强，而不是单一龙头带指数。

失效信号：
- 中报好但低于市场预期，或环比增速明显放缓。
- 毛利率未随高速产品占比提升而改善。
- 存货、预付款和应收账款增长明显快于收入。
- 美元走弱/人民币升值导致汇兑压力扩大。
- 资金从通信/电子主线持续流出，且ETF放量跌破关键均线。

## 核查状态

- 已核实：TrendForce 2026 AI光模块市场260亿美元预测；NVIDIA FY2027 Q1数据中心收入752亿美元；中际旭创2026Q1业绩；新易盛2026Q1业绩；159363光模块约50%口径；2026-06-30通信板块资金流。
- 存疑：具体“光模块费用占网络设备成本”的单一比例口径。不同报告使用系统设备、数据中心IT设备、光模块自身BOM等不同分母，不能混用。
- 未证实：中际旭创或新易盛对某客户的“独家订单”类市场传言，未作为结论依据。
